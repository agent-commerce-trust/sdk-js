# Code Of Conduct

This repository follows the Contributor Covenant Code of Conduct, version 2.1.

## Expected Behavior

- Be respectful of differing viewpoints and implementation constraints.
- Give constructive, specific feedback.
- Accept responsibility for mistakes and correct them promptly.
- Keep discussions focused on what helps the project and its users.

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory language.
- Publishing private information without explicit permission.
- Personal attacks, sustained disruption, or bad-faith review behavior.
- Any conduct that maintainers reasonably judge inappropriate in a professional open-source setting.

## Reporting

Report conduct concerns to `odyssey@airheart.com`. Maintainers will review reports promptly and fairly, and will preserve reporter privacy as far as practical.
