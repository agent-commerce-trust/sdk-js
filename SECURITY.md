# Security Policy

Security reports are welcome for the Agent Commerce Trust JavaScript packages, build pipeline, release scripts, and package metadata.

## Reporting A Vulnerability

Email security reports to `odyssey@airheart.com` with `[security]` in the subject line.

Please include:

- A concise description of the issue
- Affected package name and version
- Reproduction steps or proof-of-concept material when safe to share
- Any known impact on mandate construction, canonical serialization, package publishing, provenance, or deferred-stub metadata

Do not open a public GitHub issue for an active vulnerability before maintainers confirm disclosure timing.

## Response Targets

- Initial acknowledgement: 1 business day
- Triage update: 3 business days
- Remediation plan or non-applicability rationale: 10 business days for confirmed issues

If a report affects a published package, maintainers will coordinate an advisory, patched release candidate, and downstream notification using the process in `RELEASING.md`.
